# Whatsbetter Creator Cabinet — требования к дизайну

## 1. Общая цель

Кабинет должен выглядеть как современный продукт для creator economy и аналитики, а не как:

- тяжелая CRM;
- бухгалтерская система;
- рекламный кабинет с десятками фильтров;
- ERP;
- типовая bootstrap-админка.

Главные ощущения:

```text
легкий
спокойный
современный
дорогой
понятный
аналитический
```

Приложенные референсы задают верное направление:

- много воздуха;
- светлый фон;
- белые карточки;
- крупные скругления;
- аккуратная типографика;
- минимум тяжелых рамок;
- красивое визуальное представление данных;
- ограниченная палитра;
- мягкие акценты.

---

# 2. Основной UX-принцип

## Один экран — одна главная история

Например Overview:

```text
просмотры
→ переходы
→ покупка
→ доход
```

Audience:

```text
кто моя аудитория
→ чем интересуется
→ что для нее важно
→ какие товары ей подходят
```

Sales:

```text
что купили
→ где купили
→ сколько GMV
```

Не делать все блоки одинаково важными.

# 7. Градиенты

Референсы используют градиенты, но в продукте применять ограниченно.

Можно:

- hero/accent card;
- earnings highlight;
- tiny decorative element;
- subtle chart fill.

Нельзя:

- gradient на каждой card;
- многоцветный фон рабочей области;
- neon UI.

Основная рабочая поверхность — светлая нейтральная.

---

# 8. Карточки

Default:

```css
background: #FFFFFF;
border: 1px solid #E8EBF0;
border-radius: 20px;
```

Large analytics:

```text
radius: 24 px
```

Compact:

```text
16–18 px
```

Тень:

```css
box-shadow:
  0 1px 2px rgba(15,23,42,.02),
  0 8px 24px rgba(15,23,42,.04);
```

Card anatomy:

```text
title
optional subtitle
optional control
content
```

Не помещать каждый KPI внутрь нескольких вложенных рамок.

# 11. Цифры

Аналитические числа — главный визуальный элемент.

Хорошо:

```text
3,8 млн ₽
+19,5%
```

Плохо:

```text
Общий валовой объем продаж:
3 800 000 рублей
```

На card — компактное значение.

В tooltip/table — точное.

---

# 12. KPI cards

Overview:

```text
Просмотры
Переходы
Заказы
Выкуплено
GMV
Мой доход
```

На desktop:

```text
6 в ряд
```

Если 1280 не помещает красиво:

```text
3 × 2
```

Каждая card:

- label;
- number;
- growth;
- optional sparkline.

Иконка не обязательна.

---

# 13. Главная funnel-компонента

Не использовать тяжелую 3D-воронку.

Предпочтительно desktop:

```text
100 000        18 400        4 700        1 260        1 035
Просмотры  →   Переходы  →   Корзины  →   Заказы  →    Выкуплено
             18,4%          25,5%         26,8%         82,1%
```

Можно сделать следующие блоки немного уже/светлее.

Отдельный money summary:

```text
GMV 3,8 млн ₽
Доход 380 тыс ₽
```

# 14. Графики

Основные типы:

```text
line
area
vertical bar
horizontal bar
stacked bar
funnel
heatmap
```

Sankey использовать только там, где путь действительно понятен.

---

# 15. Line charts

Для:

- views;
- clicks;
- orders;
- GMV;
- income;
- active audience.

Стиль:

```text
stroke 2–2.5 px
минимум grid lines
points только hover
умеренный smoothing
```

Не помещать chart в дополнительную внутреннюю рамку.

---

# 16. Area fill

Допустим:

```text
5–10% opacity
```

Не делать насыщенный gradient fill.

---

# 17. Horizontal bars

Лучший вариант для:

- сферы интересов;
- критерии;
- товары;
- sales channels.

Если категорий больше 4 — horizontal bar обычно предпочтительнее pie.

---

# 18. Pie / donut

Использовать редко.

Допустимо:

```text
3–4 sales channels
commission statuses
```

Не использовать для:

```text
12 interests
10 criteria
10 products
```

---

# 19. Heatmap

Хорош для cross-interest.

Ограничить основной report примерно:

```text
6 × 6
```

Для большего количества — отдельный drilldown.

---

# 20. Цвета графиков

Не назначать каждой серии случайный цвет.

Базовая последовательность:

```text
primary blue
secondary violet
green
warm amber
neutral gray
```

На одном графике:

```text
2–4 активных цвета
```

Previous period:

```text
gray
dashed
lower opacity
```

# 26. Tables

Стиль:

```text

без vertical borders
light horizontal separators
numeric right aligned
status soft pill
subtle hover
sticky header при необходимости
```

Пример:

```text
Контент                     Просм.  CTR   Выкуп.   GMV      Доход
─────────────────────────────────────────────────────────────────
Что лучше: кремы / VK       42K     17%   310      1,1M ₽   110K ₽
```

# 27. Filters

В header максимум:

```text
[30 дней ▼] [Кампания: Все ▼] [Площадка: Все ▼]
```

Редкие:

```text
[Фильтры]
```

Не показывать одновременно 8 dropdown.

---

# 28. Header

Пример:

```text
Главная
Аудитория и продажи

                         [30 дней ▼] [Сравнить ✓]
```

Без огромного hero header.

---

# 29. Insight blocks

Допустимо 1–2 на страницу:

```text
↑ Telegram дал на 24% выше конверсию в заказ,
чем среднее по вашим публикациям.
```

Только на основе данных.

Не делать AI-chat bubble центральным элементом.

---

# 30. AI assistant

Для первой версии:

```text
Спросить об отчете
```

может быть secondary action.

Не делать чат главным смыслом кабинета.

---

# 31. Empty state

```text
Пока недостаточно данных

После первых переходов из публикаций здесь появится
структура интересов вашей аудитории.
```

Минимальная иллюстрация или вообще без нее.

---

# 32. Skeleton loading

Использовать skeleton:

- KPI;
- chart;
- table.

Не использовать fullscreen spinner.

---

# 33. Animation

```text
150–250 ms
```

Подходит:

- hover;
- filter;
- tab;
- chart reveal;
- subtle number transition.

Не использовать:

- bounce;
- parallax;
- continuous floating animation.

# 38. Что нельзя делать

Не перегружать:

- десятками KPI;
- множеством pie charts;
- 10 цветами;
- всеми фильтрами одновременно;
- мелким текстом;
- плотными tables;
- тяжелыми borders;
- огромными shadows;
- gradient на каждой card.

Страница должна иметь:

```text
1 главный report
2–3 средних
несколько supporting blocks
```

---

# 39. Visual density

Цель первого viewport:

```text
6 KPI + funnel + 1–2 крупных блока
```

Не:

```text
18 маленьких равнозначных карточек
```

---

# 40. Accessibility

Минимум:

- WCAG AA для текста;
- visible keyboard focus;
- charts имеют текстовые значения/aria;
- status не кодируется только цветом;
- clickable area от 36–40 px.

---

# 41. Screenshot-ready

Каждый ключевой экран должен хорошо выглядеть на:

```text
1440×900
```

В screenshot должны быть видны:

- page title;
- основные KPI;
- основной chart/report;
- логика страницы.

---

# 42. Итоговый визуальный ориентир

> Светлый современный аналитический кабинет с большим количеством воздуха,
> крупными белыми карточками, минимальными рамками, аккуратной типографикой
> и одним основным синим акцентом. Данные — главный визуальный контент.

Ощущение:

```text
"это продукт для блогера и бизнеса"
```

а не:

```text
"это внутренняя техническая админка"
```.
